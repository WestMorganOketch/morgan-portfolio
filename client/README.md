# Portfolio design notes

This project is a responsive personal portfolio focused on presenting professional work clearly and consistently.

## Design

- Clear page structure and navigation
- Responsive layouts for desktop and mobile
- Readable typography and consistent visual styling
- Light and dark appearance options
- Motion preferences that respect reduced-motion settings

## Content

The public website is intended to show selected projects, professional background, skills, and contact information. Publish only content that is meant to be public.

For setup, database, deployment, or security documentation, use a separate private location. This repository is public, so anything committed here—including this file and earlier versions in Git history—may be visible to others.
